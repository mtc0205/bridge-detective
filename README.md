# 危桥侦探 Bridge Detective(参赛作品)

第一人称桥梁结构检测游戏 —— 群核科技 Aholo 全球 3D AI 黑客松。

玩家扮演检测工程师漫游桥梁,用「检测仪」找出结构缺陷,按真实规范
(JTG/T H21-2011《公路桥梁技术状况评定标准》简化版)选择缺陷类型与严重度,
结算时输出三部件加权 BCI 评级与可导出的检测报告。

**当前版本:M3 打磨完成**(2026-11-12)。玩法全链路:观察 → 判定(含裂缝
量测参考尺)→ 反馈 → 记录 → 结算 → 报告(下载 Markdown / 打印 PDF)→
漏检回放;三案件(城市高架教学关 / 山村石拱桥应急检测 / 钱塘江大桥 1937
战损评估,含史实尾声卡)均为参数化程序资产占位,Lux3D glb 可通过
`asset.glb` 字段即插热切换(见下);随时限推进的日落倒计时光影 + 首次
引导 + WebAudio 音效。每晚进度见 PROGRESS.md。

## 快速开始

```bash
npm install       # 安装依赖(three@0.165 / vitest)
npm run dev       # 开发服务器(默认 http://localhost:5173)
npm run build     # 类型检查 + 产线构建(输出 dist/,纯静态可托管)
npm run preview   # 本地预览构建产物
npm run test      # vitest 单元测试(纯逻辑,90 个用例)
npm run typecheck # 仅 tsc --noEmit
```

桌面端 Chrome / Edge(需要 WebGL 与 Pointer Lock;不支持移动端)。

## 操作

| 按键 | 功能 |
| --- | --- |
| `W A S D` / 方向键 | 移动(眼高 1.65m,贴地 + 重力) |
| 鼠标(点击画面锁定指针) | 视角 |
| `E` | 对准热点微光标记后打开检测弹窗 |
| `G` | 判定图鉴(16 类缺陷的观察要点 / 分级规则 / 处治建议,计时暂停) |
| `M` | 音效开关(WebAudio 合成音效,任何界面下生效) |
| `1-7` / `Q W E` | 弹窗内快选缺陷类型 / 严重度 |
| `Enter` | 提交判定 |
| `Shift` | 加速跑 |
| `N` / `P` | 漏检回放中切换上一处 / 下一处 |
| `Esc` | 释放指针 / 暂停 |

动线:沿桥面从西桥头走到东桥头 → 经两端路堤坡道下到地面 →
从桥南侧绕进桥下便道 → 仰头检查梁体、墩柱与支座。

## 玩法循环(M1 完整版)

选案件 → 开场卡 → 漫游 → 准星对准微光标记按 `E` → 近景描述 + 选
【缺陷类型 × 范围内 7 类】+【严重度 轻/中/重】(或「无缺陷·不标记」)→
即时判定反馈(正确 +100 / 严重度偏差 +40 / 类型误判 0 / 误报 −50 / 放走真缺陷 0,
附规范依据)→ 全部处理完或时限到 → 结算:

- **技术状况评定**:三部件 BCI(桥面系 0.2 / 上部 0.4 / 下部 0.4 加权)
  + 主要部件拖累 + 关键隐患条款(支座脱空·重 → BCI≤57 四类)→ 1~5 类等级;
- **检测报告页**:缺陷清单(位置/部位/判定/规范依据/处治建议)+ 评定结论 +
  漏检误报 + 质量统计;**下载 .md** / **浏览器打印或另存 PDF**;
- **漏检回放**:场景内红色光柱信标逐处定位(N/P 切换,WASD 自由复盘)。

教学关 10 个检测点、7 类缺陷、1 个「完好诱饵」(正确答案是「无缺陷」,
考察不误报);三部件各有布点,裂缝三形态齐备(网状 / 横向 / 纵向)。
案件二(石拱桥)10 点 / 8 类,暴雨后应急叙事,拱石松动触发关键条款 → 四类;
案件三(钱塘江 1937)12 点 / 6 类钢构病害,五孔落江两墩毁的可见简化占位,
全计入 → 上部坍塌 → 五类危桥,结算后可翻「尾声 · 此桥必复」史实卡
(1948《大公报》修复报道 / 1953 全面修复 / 今日服役,文案经 SOURCES.md 核对)。

## 关卡编辑器(内部工具,开发模式)

`npm run dev` 后访问 `http://localhost:5173/?editor=1`(可用 `&level=stone-arch`
或 `&level=qiantang-1937` 选底稿关卡):

- 点击画面锁定指针后 **左键** 在桥体表面摆放 / 选中热点,**右键** 删除,`F` 传送到准星处;
- `WASD + Q/E` 飞行(Shift 加速),方向键 / PgUp PgDn 微调选中热点,`[ ]` 切换,`Del` 删除;
- 右侧属性面板:关卡元信息、弹窗类型范围勾选、检测点全字段(答案 / 部件 / 坐标 / 双文案)、
  「出生点 = 当前视角」一键设置;
- **保存**:parseLevel 预校验 → 下载 `{id}.json` + 复制到剪贴板,放入 `src/levels/` 即成新关卡;
  支持导入 JSON 回显继续编辑。

## 资产接口(M2 替换点)

玩法层只依赖 `src/bridge/levelAsset.ts` 的 `ILevelAsset`:

- `root` 场景内容;`colliders` AABB 阻挡;`surfacesAt(x,z)` 多层可行走面;
- `decorateScene(scene)` 天空 / 雾 / 光照;`update` / `dispose`。

Lux3D 接入路径:导出 glb 放 `public/assets/levels/{案件id}.glb`,
关卡 JSON 写 `"asset": { "glb": "/assets/levels/xxx.glb" }` 即热切换视觉
(碰撞 / 出生点 / 热点坐标系仍用程序化常量,加载失败静默回退占位资产)。

## 已知限制(M3 后)

- 三案件均为程序化素色占位,损伤无贴图表现(近景为文字描述 + 结构可视化),Lux3D 资产生成后接入(两步:glb 入 `public/assets/levels/` + JSON 加 `asset.glb` 字段)
- 钱塘江场景为「两孔落江 + 两墩毁」的可见简化(史实为五孔落江),开场卡已明示;钢桥远观热点半径 14/18m 待实机手感调校
- 日落光影为雾/灯/色罩插值,非动态太阳轨迹;音效为 WebAudio 合成占位
- 不支持移动端触控(赛事截止前视余量评估降级方案)
